# Emerging Technology Adoption Agent

This specialist evaluates a context-specific management action for an emerging technology. It does not select a vendor, approve procurement, or replace security, legal, architecture, or operational review.

The agent uses the common three-level analysis and the decision rules in `specialist_instructions.md`. The included cases compare a 1,000-employee established SaaS company with a four-person software startup using LLM Coding Assistants for comparable software-development work.
